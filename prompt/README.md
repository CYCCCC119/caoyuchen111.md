# AI 交流提示词追溯记录

本目录用于归档课程设计过程中与 AI 工具（Claude Code 等）的交流记录，作为 Vibe Coding 开发范式的过程档案，保证开发过程可追溯。

## 记录规范

- **文件格式**：JSON（每条记录为一个对象，多个记录组成数组）。
- **命名规则**：`YYYY-MM-DD_阶段名.json`，例如 `2026-08-28_数据准备阶段.json`。
- **更新时机**：每个开发阶段结束时同步更新；**在上下文压缩（context compaction）前务必及时备份并提交**，避免记录丢失。
- **内容要求**：记录原始提示词（prompt）、AI 执行摘要、使用工具、产出文件，形成完整的「需求 → 执行 → 产出」链路。

## 记录字段说明

```json
{
  "stage": "数据准备阶段",     // 所属阶段
  "date": "2026-08-28",        // 日期
  "model": "deepseek-v4-pro",  // 使用的模型
  "records": [
    {
      "seq": 1,                 // 序号
      "role": "user",           // user=人类提示词 / assistant=AI 响应摘要
      "prompt": "...",          // 原始提示词（或 AI 工作摘要）
      "tools_used": ["Read"],   // 使用的工具
      "outputs": ["..."],       // 产出文件
      "notes": "..."            // 备注
    }
  ]
}
```
